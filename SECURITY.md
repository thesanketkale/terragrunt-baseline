# Security Policy

## Supported Versions

| Version | Supported          |
| :---    | :---               |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of `terragrunt-live-template` seriously. If you believe you have found a security vulnerability, please do NOT open a public issue or discussion.

### Private Reporting via GitHub
Please report vulnerabilities privately via [GitHub Security Advisories](https://github.com/thesanketkale/terragrunt-live-template/security/advisories/new).

### Email Contact
Alternatively, you may email security reports directly to `security@thesanketkale.com`.

### Our Process
1. We will acknowledge receipt of your vulnerability report within 48 hours.
2. We will investigate and provide an assessment and timeline for remediation.
3. We will release a security advisory and patched release once the fix is verified.
